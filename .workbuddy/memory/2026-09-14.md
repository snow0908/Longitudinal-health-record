## 脱敏规则 — 机构多选下拉（第三轮）
- 将「机构」由原生单选 `<select>` 改为自定义多选下拉组件，显示区展示「已选择（n）」。
- 下拉面板每行带复选框，选中项蓝色高亮（#E8F1FF 背景 + 主色文字），可多选。
- 点击面板外部 / 再次点击触发器 / 关闭弹框时自动收起下拉。
- 科室下拉改为合并所有已选机构的科室（去重）。
- 表格筛选机构条件改为 OR 关系：`u.orgId ∈ buSelectedOrgs`。
- 查询按钮校验至少选择一个机构；重置按钮恢复全选机构。
- 模拟数据扩展为 8 个机构（村卫生室/卫生院名称贴近截图），并补充对应科室与人员池。
- 默认选中前 4 个机构，弹框打开即显示「已选择（4）」，与参考截图一致。

## 脱敏规则 — 绑定科室 / 绑定角色弹框（第四轮）
- `bindEntity()` 按 scope 路由：person→openBindUserModal，dept→openBindDeptModal，role→openBindRoleModal。
- 新增 `#bindDeptModal`（关联科室）：样式复用 `.bind-user-modal`，筛选区 = 机构多选（bd* 独立状态，同人员弹框多选逻辑）+ 关键字；表格列 = 复选框 / 科室编码 / 科室名称 / 机构名称；确定回填 `deptBindData`。
- 新增 `#bindRoleModal`（关联角色）：筛选区 = 关键字（角色名称/编码/类型/描述搜索）；表格列 = 复选框 / 角色编码 / 角色名称 / 角色类型 / 角色描述；确定回填 `roleBindData`。
- 数据源：`bindDeptPool`（从 bindUserOrgs+bindUserDepts 派生，带 code/name/orgId/orgName）、`bindRolePool`（8 个角色，带 id/name/type/desc）。
- 弹框交互与人员一致：多选/单选、选中数量、全选(仅可见行)、确定回填底部浮层、取消/Esc/蒙层关闭。

## 脱敏规则 — 勾选状态筛选 + 弹框加宽（第五轮）
- 三个绑定弹框（人员/科室/角色）筛选区均新增「勾选状态」下拉：全部 / 未勾选 / 已勾选（id 分别为 buCheckStatus / bdCheckStatus / brCheckStatus）。
- 过滤逻辑：在 getBindUserVisible / getBindDeptVisible / getBindRoleVisible 中按各自选中集合（buSelected username / bdSelected id / brSelected id）判断；"已勾选"仅保留集合中项，"未勾选"剔除集合中项，"全部"不过滤。
- 勾选状态与机构/科室/关键字一致，点击「查询」生效；open / reset 时重置为「全部」。
- 弹框尺寸由 760×560 加宽至 900×560（min-width 720→860），`.bind-user-modal` 共用样式，三个弹框同步加宽。
