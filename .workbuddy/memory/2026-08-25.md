## 隐私保险箱健康档案tab BUG修复

- **症状**: 点击「健康档案」tab 页面错乱
- **根因**: 替换 box_12 内容区时，把父容器（s2-box_5 / s3-box_4）的闭合 `</div>` 标签也一起删掉了，导致 DOM 结构破坏
- **修复**: 
  - 只替换 box_12 本身（用 div 深度计数精确找到 box_12 的闭合位置），保留外层容器闭合
  - 旧绝对定位装饰元素（s2-box_21 圆点、s2-box_22 / s3-box_15 表格背景）单独移除
  - 验证: div 开闭 142:142 平衡，view-diag 段 0 差异
- **经验**: 替换嵌套 div 内容时，必须用深度计数定位闭合标签，不能简单用 find('</div>') 截断
