# 业务界面数据查询逻辑

## 文档说明

本文档记录健康全景视图/全程档案调阅系统中各业务界面的数据查询逻辑，包括列表界面的筛选条件、详情界面的查询条件，以及各 TAB 页对应的数据源表。

> 模块菜单依据移动端"健康全景视图"功能菜单梳理，分为「诊疗服务」与「健康档案」两大类。

#### 1.4.2 检验报告详情界面

| 项目 | 说明 |
| --- | --- |
| **数据源表** | 根据检验类别编码 `CJYLBBM` 判断查询路径 |
| **查询条件** | 检验报告单编号：`CJYBGDBH` |
| | 电子申请单编号：`CDZSQDBH` |
| | 就诊号：`CJZH` |
| | 患者标识：`CHZBS` |
| | 医疗机构代码：`CYLJGDM` |
| **分支逻辑** | 列表界面返回 `CJYLBBM`，据此判断查询路径 |
| **普通检验结果** | `CJYLBBM ≠ '05'` → 查询 `TB_YJJY_JYBG` 获取报告基本信息 + `TB_YJJY_JYJG` 获取检验结果 |
| **细菌结果** | `CJYLBBM = '05'` → 查询 `TB_YJJY_JYXJJG` 获取细菌检验细项结果；点击细菌结果行时，追加 `CJYXJJGID` 作为查询条件，查询药敏结果表 `TB_YJJY_JYYMJG` |
| **返回字段** | 检验报告完整内容（报告基本信息 + 检验结果明细 / 细菌结果 + 药敏结果） |

##### 检验报告详情分支查询逻辑

| 分支类型 | 判断条件 | 数据源表 | 查询条件 | 说明 |
| --- | --- | --- | --- | --- |
| 普通检验结果 | `CJYLBBM ≠ '05'` | `TB_YJJY_JYBG` + `TB_YJJY_JYJG` | `CJYBGDBH` + `CDZSQDBH` + `CJZH` + `CHZBS` + `CYLJGDM` | 先查报告基本信息，再查检验结果 |
| 细菌结果 | `CJYLBBM = '05'` | `TB_YJJY_JYXJJG` | `CJYBGDBH` + `CDZSQDBH` + `CJZH` + `CHZBS` + `CYLJGDM` | 查询细菌检验细项结果 |
| 药敏结果（细菌结果子查询） | 点击细菌结果行触发 | `TB_YJJY_JYYMJG` | `CJYBGDBH` + `CDZSQDBH` + `CJZH` + `CHZBS` + `CYLJGDM` + `CJYXJJGID` | 在细菌结果查询条件基础上追加 `CJYXJJGID` |

##### 细菌结果与药敏结果返回字段说明

**一、细菌结果卡片（父卡片）—— 数据源：`TB_YJJY_JYXJJG`（检验细菌结果表）**

| 界面显示内容 | 字段名 | 字段说明 |
| --- | --- | --- |
| 标本类型（如：血液、痰液） | `CJYBBH` | 检验标本号（标本号前缀或关联字典区分类型） |
| 报告时间（如：2026-08-31 09:30） | `DJYRQSJ` | 检验日期时间 |
| 细菌名称（如：肺炎克雷伯菌） | `CXJMC` | 细菌名称 |
| 细菌简称（如：Kpn） | `CXJJC` | 细菌简称 |
| 阴阳性状态（阳性/阴性） | `CYYXMC` | 阴阳性名称 |
| 多重耐药标签（红色徽章） | `BDZNYBZ` | 多重耐药标志（0-否，1-是） |
| 备注/警示（如：ESBL阳性株、MRSA） | `CBZ` 或 `CZJPY` | 备注 / 专家评语 |
| 卡片唯一标识（父子关联主键） | `CJLID` | 检验细菌结果ID（父表主键） |

**二、药敏结果列表（子列表）—— 数据源：`TB_YJJY_JYYMJG`（检验药敏结果表）**

| 界面显示内容 | 字段名 | 字段说明 |
| --- | --- | --- |
| 抗菌药物名称（如：头孢曲松） | `CKJYWMC` | 抗菌药物名称 |
| 药敏值/MIC（如：≥64、≤0.25） | `CYMZ` | 药敏值 |
| 检测结果（敏感/中介/耐药） | `CJCJG` | 检测结果（存储文字值） |
| 关联父表外键 | `CJYXJJGID` | 检验细菌结果ID（外键，指向父表 `CJLID`） |

**三、卡片底部统计标签（前端聚合）**

> 非数据库字段，由前端根据子表（药敏结果）数据对 `CJCJG` 字段实时聚合统计后动态渲染。

| 统计标签 | 计算方式 |
| --- | --- |
| `N种` | 该细菌下药敏记录总条数（COUNT） |
| `N敏` | `CJCJG = '敏感'` 的条数 |
| `N耐` | `CJCJG = '耐药'` 的条数 |
| `N中` | `CJCJG = '中介'` 的条数 |
