# 业务界面数据查询逻辑

## 文档说明

本文档记录健康全景视图/全程档案调阅系统中各业务界面的数据查询逻辑，包括列表界面的筛选条件、详情界面的查询条件，以及各 TAB 页对应的数据源表。

---

## 一、诊疗业务

### 1.1 门诊记录

#### 1.1.1 门诊列表界面

| 项目 | 说明 |
| --- | --- |
| **数据源表** | 就诊索引事件表（`TB_SY_JZSJ`） |
| **查询条件** | 就诊类型：`CHZJZLXBM = 1` |
| | 就诊开始时间范围：`DJZKSSJ` |
| | 医疗机构代码：`CYLJGDM` |
| **返回字段** | 就诊号、就诊开始时间、医疗机构名称、科室、医生等（按界面展示需求） |

#### 1.1.2 门诊记录详情界面

| 项目 | 说明 |
| --- | --- |
| **查询条件** | 就诊号：`CJZH` |
| | 患者标识：`CHZBS` |
| | 医疗机构代码：`CYLJGDM` |
| **加载方式** | 以 CJZH + CHZBS + CYLJGDM 作为联合查询条件，分别查询各 TAB 页对应业务数据 |

##### TAB 切换页 - 就诊记录

| 数据项 | 数据源表 | 关联条件 |
| --- | --- | --- |
| 门急诊病案首页基本信息 | `TB_MJZ_BAJBXX` | CJZH + CHZBS + CYLJGDM |
| 门急诊病案首页手术操作 | `TB_MJZ_BASSCZ` | CJZH + CHZBS + CYLJGDM |
| 门急诊病案首页诊断信息 | `TB_MJZ_BAZDXX` | CJZH + CHZBS + CYLJGDM |
| 门（急）诊处方明细记录 | `TB_MJZ_MJZCFMXJL` | CJZH + CHZBS + CYLJGDM |

##### TAB 切换页 - 检查报告（PC 端列表）

| 项目 | 说明 |
| --- | --- |
| **接口** | 检查报告列表查询接口（独立接口） |
| **数据源表** | `TB_YJJC_JCBG` |
| **查询条件** | 就诊号：`CJZH` |
| | 患者标识：`CHZBS` |
| | 医疗机构代码：`CYLJGDM` |
| **列表返回字段** | 报告号、报告名称、检查项目、检查时间、报告状态、医疗机构名称等（按界面展示需求） |

##### TAB 切换页 - 检验报告（PC 端列表）

| **接口** | 检验报告列表查询接口（独立接口） |

## 附录：通用字段说明

| 字段名 | 含义 | 备注 |
| --- | --- | --- |
| `CHZJZLXBM` | 患者就诊类型编码 | `1` 表示门诊 |
| `DJZKSSJ` | 就诊开始时间 | 用于时间范围筛选 |
| `CYLJGDM` | 医疗机构代码 | 用于机构范围筛选 |
| `CJZH` | 就诊号 | 门诊/住院等就诊唯一标识 |
| `CHZBS` | 患者标识 | 患者唯一标识 |
