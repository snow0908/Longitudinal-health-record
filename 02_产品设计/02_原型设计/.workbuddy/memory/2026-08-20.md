# 2026-08-20

## 隐私权限管理 / index.html — 头部样式美化（极光玻璃风）

**问题**：「隐私权限管理」首屏 Hero 卡片（`.privacy-header`）原版视觉寡淡：被一张半透明 PNG 覆盖冲淡了品牌蓝渐变、盾牌徽章扁平、标签只是裸文字+小点，缺乏层次与质感。

**改造（common.css + index.html 同步）**：

- **CSS（common.css `.privacy-header` 整块重写）**
  - 移除背景 PNG 覆盖，改用三层叠加：左上浅蓝径向 + 右下深蓝径向 + 135° 主品牌线性渐变（#0858D9 → #096AFF → #2A7CFF → #4F9BFF），恢复色彩饱和度与深度。
  - 圆角 8px → 16px；加 0 14px 34px -10px rgba(9,106,255,0.40) 蓝色柔光阴影 + inset 0 1px 0 rgba(255,255,255,0.32) 顶部内高光，形成「极光玻璃」立体感。
  - `::before` 左上 190px 白色高光球 + `::after` 右下 200px 青色辉光球，营造极光氛围。
  - `.shield-wrap` 升级为 52×52 玻璃徽章：`backdrop-filter: blur(14px) saturate(1.5)` + 白渐变 + 1px 白 40% 边框 + 内高光 + 柔光阴影；`::after` 右下 14px 绿色「守护中」状态点（白边+阴影）。
  - `h2` 20/500 → 22/600，字距 0.3px，文字阴影 0 1px 2px，深蓝可读性提升；新增 `max-width: calc(100% - 80px)` 避开徽章。
  - `p` 14/0.9 → 13/0.9，行高 1.6 → 1.7，字距 0.2px + 文字阴影。
  - `.header-tags` 标签由「裸文字+3px 圆点」改为 `.tag-pill` 玻璃胶囊：白 16% 底 + 白 30% 边框 + blur(8px) + 44px 圆角 + 内含 5px 白点（带 6px 发光），统一精致感。
  - 导航栏微调：`.nav-bar` 加 0 1px 0 rgba(0,0,0,0.04) 发丝分割；`.nav-title` 500 → 600 + 0.2px 字距。

- **HTML（index.html `.privacy-header` 内部结构）**
  - 新增 `<div class="header-motif" aria-hidden="true">` 包裹一枚 230×230 旋转 -8° 的填充盾牌 SVG（白 8% 透明度），作为右下角艺术水印。
  - `.header-tags` 三个短语各包成 `<span class="tag-pill"><span class="pill-dot"></span>文案</span>`；移除旧 `.tag-dot` 分隔符与 `.header-decoration` 底缘装饰条。

**效果**：Hero 卡片从扁平淡蓝升为「深蓝极光 + 玻璃徽章 + 绿色守护点 + 盾牌水印 + 玻璃胶囊标签」的医疗隐私专属视觉，质感与信任感显著提升。改动仅限 `隐私权限设置/` 目录，未影响其他子页面（`.privacy-header`/`.tag-pill`/`.header-motif` 均为该页专属类）。

## 隐私权限管理 / index.html — 头部风格收敛对齐个人中心

**问题**：上一轮的「极光玻璃风」虽强化了医疗隐私感，但视觉密度与该项目「个人中心」首页的「浅薄荷蓝+留白克制」不一致——前者用大块深蓝 + 玻璃模糊 + 强阴影，后者用淡蓝渐变 + 白色卡片 + 留白。需把隐私页头部收敛到与个人中心一致的设计语言。

**改造（common.css + index.html 同步）**：

- **CSS（common.css `.privacy-header` 整块重写）**
  - 背景从深蓝极光渐变 → 浅薄荷蓝渐变 `linear-gradient(135deg, #DBEDFE 0%, #E5F2FA 55%, #F0F8FE 100%)` + 左上白色径向高光 + 右下浅蓝径向；配色映射个人中心家庭成员卡片。
  - 边框：`1px solid rgba(9,106,255,0.08)` 淡描边；阴影从 14px 34px → 2px 12px `rgba(9,106,255,0.06)` 极弱。
  - 文字颜色：白 → `var(--text-primary)` / `var(--text-secondary)`，与个人中心语义一致。
  - `h2` 22/600 → 18/600，新增 `.accent` 修饰类（用 `var(--primary)` 突出关键短语）。
  - 移除 `::before` 极光白球；`::after` 由青色辉光球改为右上 44px SVG-mask 装饰盾牌（呼应个人中心 `group_2` 插画位置，0.45 透明度），与标题文案水平错开。
  - `.shield-wrap` 52px 玻璃徽章 → 44px 扁平常态徽章（`#E4EEFF → #C9DEFF` 渐变底 + 1px 主蓝 12% 边框 + 24px 主蓝描边盾牌 + 6px 柔光阴影），与个人中心图标视觉重量一致；移除右下绿色守护点（避免与浮起风格冲突）。
  - `.tag-pill` 玻璃胶囊 → 扁平淡蓝 chip（`rgba(228,238,255,0.85)` 底 + 1px 主蓝 18% 边框 + 主蓝文字），移除 `.pill-dot` 与发光。

- **HTML（index.html `.privacy-header` 内部结构）**
  - 移除 `<div class="header-motif">` 230×230 盾牌水印。
  - `<h2>健康档案隐私保护</h2>` → `<h2>健康档案<span class="accent">隐私保护</span></h2>`，"隐私保护"用主蓝强调。
  - 标签去掉 `<span class="pill-dot">`，三个 chip 仅留文案；副文案"国家卫健委"简化"卫健委"避免 chip 过宽换行。

**效果**：Hero 卡片从「深蓝极光玻璃」收敛为「浅薄荷蓝+扁平徽章+淡蓝 chip」，与个人中心 `section_4` 家庭成员卡视觉语言一致（同色系、同阴影强度、同徽章尺度），整体医疗隐私感仍在但更克制不夺目。改动仅限 `.privacy-header`/`header-tags`/`shield-wrap`/`tag-pill`（隐私主页专属类），未影响其他子页面。

## 隐私权限管理 / index.html — 头部改全出血紧凑横幅（消除搁置感）

**问题**：上一版头部仍是「独立卡片」（圆角 16px + 1px 边框 + 阴影 + 16px 外边距），视觉上像一个「贴上去的块」，搁置感强；且高度约 180px 偏高。个人中心头部是**全出血渐变背景**（`section_1` 状态栏+导航+内容一体，无卡片感）。

**改造（common.css + index.html 同步）**：

- **CSS（common.css）**
  - `.page` 内边距改为 `padding: 0 16px 100px`（去掉顶部留白）。
  - `.privacy-header` 取消独立卡片：去掉圆角/边框/阴影，改 `margin: 0 -16px 16px` **全出血撑满宽度**，只保留 `border-bottom: 1px solid rgba(9,106,255,0.06)` 发丝分割；渐变改纵向 `linear-gradient(180deg, #E6EFFC 0%, #EDF4FB 100%)` + 左上白高光 + 右下浅蓝暗角，与页面底色自然过渡。
  - 移除 `::after` 装饰盾牌 mask（紧凑布局下不再需要）。
  - `.shield-wrap` 44px → **36px 紧凑徽章**（圆角 10px，图标 20px）。
  - 新增 `.ph-row`（flex 水平排列徽章 + 文案）与 `.ph-copy`；`h2` 17px/600、`p` 12px，标题与描述同行展示。
  - `.header-tags` 上移为 `margin-top: 12px`，chip 字号 11px、内边距 4px 9px，整体压缩。
  - 高度由约 180px 压缩至约 100px（减少约 45%）。

- **HTML（index.html）**
  - `.privacy-header` 内部重构：`shield-wrap` + `ph-copy`（h2+p）包进 `.ph-row` 同一行，标签行保留在下方。

**效果**：头部从「悬浮卡片」变为「与页面融为一体的全出血浅蓝横幅」，紧贴导航栏下方，与个人中心 `section_1` 一体式渐变风格对齐；高度减半，内容一目了然。改动仅限 `隐私权限设置/` 目录专属类。

## 隐私权限管理 / index.html — 复用个人中心渐变 PNG，Banner 加深突出

**问题**：用户参考个人中心截图，要求隐私页「从顶部到统计模块做渐变效果，中间 banner 采用家庭成员类似的加深突出一点的效果」。此前隐私页用 CSS 渐变模拟，与个人中心实际 PNG 渐变存在色差与质感差异；统计条为白底卡片，与上方渐变背景割裂。

**改造（common.css + index.html 同步）**：

- **HTML**
  - 新增 `.hero-wrapper` 容器，将「状态栏 + 导航栏 + `.privacy-header` + `.stat-bar`」整体包裹，形成从顶部到统计模块的一体渐变区域。
  - `.privacy-header` 内部新增 `.privacy-header-inner` 内层卡片容器，对应家庭成员卡片的内层浅色底。

- **CSS**
  - `.hero-wrapper` 背景直接复用个人中心 `section_1` 同款 PNG（`SketchPnge0c4edcb...png`），`background-size: 100% 100%`，实现与个人中心完全一致的全出血蓝色渐变。
  - `.status-bar` / `.nav-bar` 背景改为 `transparent`，移除导航栏发丝阴影，使其融入渐变背景。
  - `.privacy-header` 背景复用家庭成员管理 `section_4` 同款深色 PNG（`SketchPng47c8cb17...png`），`margin: 8px 16px 12px`、`border-radius: 12px`，形成在个人中心渐变底色上「加深突出」的卡片效果。
  - `.privacy-header-inner` 背景复用家庭成员管理 `group_1` 同款浅色 PNG（`SketchPng66d51ba5...png`），`border-radius: 10px`，承载标题、描述与标签内容。
  - `.stat-bar` 改为透明毛玻璃卡片：背景 `rgba(255,255,255,0.35)`、`backdrop-filter: blur(4px)`，数字颜色改为深色，整体融入渐变区而不显白块割裂。
  - `.hero-wrapper` 底部保留 16px padding 与 16px margin-bottom，与下方「隐私设置」标题自然过渡。

**效果**：隐私页首屏从「CSS 模拟浅渐变 + 白底统计条」升级为「个人中心同款 PNG 渐变 + 家庭成员卡片同款加深 Banner + 透明统计条」，与个人中心视觉语言高度统一，中间 Banner 明显加深突出。改动仅影响 `隐私权限设置/index.html` 与 `common.css` 的 `.hero-wrapper`、`.privacy-header`、`.stat-bar` 相关类，未影响子页面。
